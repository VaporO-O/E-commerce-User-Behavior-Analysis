# A/B 测试方案：提升「浏览 → 加购」转化率

> **数据说明**：本数据集为观测数据，不存在真实的实验组 / 对照组，无法直接用于因果推断。本文件给出完整的实验设计与分析方法论，实验数据由 [`module3_ab_simulation.ipynb`](module3_ab_simulation.ipynb) 按设定参数模拟生成，结论用于演示方法，不代表真实业务效果。

---

## 1. 背景

模块 1 的用户级转化漏斗显示，浏览 → 加购是整条链路最大的流失环节：

| 环节 | 用户级转化率 |
| --- | --- |
| 浏览 → 加购 | **19.9%** |
| 加购 → 购买 | 44.7% |
| 浏览 → 购买（整体） | 8.9% |

加购→购买相对健康，主要漏损发生在「浏览→加购」。本实验针对该环节的一项产品改动评估其因果效应。

## 2. 干预与假设

- **对照组（Control）**：现有商品列表 / 详情页。
- **实验组（Treatment）**：增加「加入购物车」快捷按钮与限时提示，降低加购操作成本。
- **原假设 H₀**：p_T = p_C
- **备择假设 H₁**：p_T ≠ p_C（双侧）

其中 p 为「浏览→加购」转化率。

## 3. 指标体系

| 类型 | 指标 | 定义 |
| --- | --- | --- |
| 主指标（OEC） | 浏览→加购转化率 | 加购用户 / 浏览用户（用户级二元结果） |
| 护栏指标 | 加购→购买转化率 | 防止仅把低意向用户灌入购物车而拉低下游 |
| 护栏指标 | 人均 GMV | 确保上游提升不以整体成交价值为代价 |
| 数据质量 | SRM（样本比失衡） | 实际分流比对 50/50 的卡方检验 |

## 4. 统计设计

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| 随机化单元 | 用户级 | 同一用户稳定分到同一组（hash 分桶），避免同人跨组污染，兼容留存等长期指标 |
| 分流比 | 50 / 50 | |
| 基线 p₀ | 0.199 | 取自模块 1 |
| MDE（最小可检测效应） | 绝对 +2pp（0.199 → 0.219，相对 +10%） | 业务上有意义的提升下限 |
| 显著性水平 α | 0.05（双侧） | |
| 统计功效 1−β | 0.80 | |
| 检验方法 | 两比例 z 检验（正态近似） | nₚ̂ 远大于 5，近似成立；卡方检验等价可作交叉验证 |

## 5. 样本量

等组样本量，对立假设下采用各自方差、零假设下采用合并方差：

```
n_per_arm = [ z_{α/2}·√(2·p̄·(1−p̄)) + z_β·√(p_C·(1−p_C) + p_T·(1−p_T)) ]² / (p_T − p_C)²
```

其中 `p̄ = (p_C + p_T)/2 = 0.209`，`z_{0.025} = 1.95996`，`z_{0.80} = 0.84162`。

| 量 | 值 |
| --- | --- |
| σ₀ = √(2·p̄·(1−p̄)) | 0.57501 |
| σ₁ = √(p_C·q_C + p_T·q_T) | 0.57484 |
| **n / 组** | **≈ 6,487 → 取 6,500** |
| **合计** | **≈ 13,000** |

> 该样本量在 α=0.05、双侧下对 +2pp 效应可达约 80% 功效（notebook 中以闭式功效函数与蒙特卡洛双重验证）。

## 6. 实验时长

时长 = 所需总样本量 / 日均合格曝光（浏览用户数），并向上取整到**完整自然周**以抵消周内季节性，建议运行 ≥ 1–2 个完整周。在全量（非 1% 抽样）流量下，样本量积累很快，时长约束主要来自「覆盖完整周期 + 规避新奇效应」而非样本量本身。

## 7. 分析方案（预先登记）

1. **主检验**：双侧两比例 z 检验，报告 p 值。
2. **效应估计**：绝对差 Δ̂ = p̂_T − p̂_C，及其 95% 置信区间（Wald；边界情形用 Newcombe）。
3. **决策规则**：当 p < 0.05、Δ̂ > 0 且护栏指标无显著恶化时，建议上线；否则不上线或迭代后重测。
4. **有效性威胁与控制**：
   - **SRM**：上线后先用卡方检验核对实际分流比，失衡则判定实验无效。
   - **多重比较**：护栏指标仅作监控；若纳入决策，用 Bonferroni 校正。
   - **新奇 / 学习效应**：覆盖完整周期，必要时剔除首日。
   - **窥视（peeking）**：不做无校正的中途多次检验；如需期中分析，采用 alpha-spending（如 O'Brien–Fleming 边界）。
